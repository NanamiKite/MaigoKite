# MaigoKite 交付路线与状态

> 最后更新：2026-10-31。
> 这份路线图说明项目现在能做什么、还缺什么，以及接下来先做什么。功能要求见 [需求与验收](../requirements/RequirementList.md)。

## 1. 已实现的核心能力

排序原则：先让一个实际任务从发起到完成都能正常工作，再增加功能；尽量复用成熟实现。

```text
通用执行闭环 → 日常可靠性与手机远程 → 经验证的个人工作流 → 扩展分发与多设备体验
```

执行链只有一条：FastAPI → AgentCore → LangGraph Runtime → 原生工具 / MCP → PermissionPolicy / HITL → 产品事件。会话管理、工具权限检查、事件投影和扩展目录分别在 `ConversationService`、`ProductToolMiddleware`、`RunProjection` 和 `ExtensionCatalog` 中，所有权与状态划分见 [运行时设计](../design/AgentRuntime.md)。

| 能力 | 现状 |
| --- | --- |
| 模型与对话 | Python HTTP/WS 聊天、真实文件读取与工具回注、实时事件/历史/快照终态一致；显式搜索不调用模型。支持 OpenAI、Anthropic、Ollama 和 OpenAI-compatible，thinking 按模型能力校验。 |
| 权限审批与恢复 | 只读 / 工作区访问 / 完全访问三种模式；逐项审批、有限期窄授权、参数 hash 与审批版本校验。文件任务可在 Core 重启后续接；拒绝写入后可改读文件并完成。 |
| 持续任务与进程 | Linux 命令沙箱（bubblewrap，可选 Windows SRT）；模型流取消、进程中文 stdin / EOF / 停止。 |
| 浏览器 | 官方 Playwright：临时上下文与具名 persistent context、上传/下载/截图、私网 URL 拒绝、持锁取消回收。 |
| MCP / Skill | 官方 SDK stdio 调用与取消复用；配置保存与应用分离、失败保留健康配置、Core 重启加载已生效配置；磁盘 Skill 扫描带预算。 |
| 只读子 Agent | 单层只读 delegate，可指定模型，共享父任务预算，独立对话页签。 |
| 手工记忆与聊天分岔 | 按文件夹维护长期信息，文件夹/对话双开关；可从某条回复分岔出新对话。 |
| 文本与文档附件 | 文本、PDF、DOCX、XLSX、PPTX 快照，目录/查找/按需回读，PDF 页图与可选本机 OCR。 |
| 图片输入 / 生成 / 预览 | 两种生图 API、权限/取消/重启、静态预览安全边界。 |
| 结构化任务结果 | 单任务 JSON Schema、结果校验与原子保存、结果 API。 |
| 用量统计与额度查询 | 本地用量聚合、统计页、DeepSeek / OpenRouter 手动额度查询。 |
| 提示词安全审查 | 独立决策模型（`jev_like` / `laya` / `openai` 格式），主模型调用前审查，高风险结果走提问/恢复链路。 |
| Web / Electron | Vue 3 前端、Electron 44 桌面端、每次启动随机凭据的本地 API 认证。 |
| 天线设计扩展 | 独立 Python 包，17 个 MCP 工具：项目准入、尺寸搜索、两档网格复核、补画、候选包导出、理想匹配。 |

天线扩展的 OB11 案例可作参考：r04 通过真实 stdio MCP 跑完 `plan_design → design → get_delivery`，399 次求解准入（搜索 393、网格复核 6），131 个完整三频候选、5 代，约 339.6 秒；r09 在 40/42/44 段三组网格上三个频点均满足既定增益/F/B 目标，最低增益 7.78–8.86 dBi，最低 F/B 25.0–26.6 dB。

## 2. 测试覆盖与性能基准

测试入口与命令见 [测试与验收](../testing/TestPlan.md)，评测任务集见 [Agent 行为评测](../testing/AgentEvals.md)。

**覆盖范围**

- 后端验收（`pytest scripts/acceptance` + 进程恢复 / HTTP 集成）：聊天工具循环、审批驳回后继续、流取消、扩展重载/重启、子模型、记忆/分岔、中文进程交互、生图协议、审批跨进程恢复、文件写入前后崩溃点。
- 真实 GUI（`gui_personal_agent.py`、`gui_media_features.py`、`gui_desk_background.py`、`gui_desk_electron.py`、`gui_desk_runtime.py`）：标签切换/重命名/关闭重开与草稿保留、正文调宽与刷新还原、图片上传/生成/预览、案头背景对比度、Electron external-runtime。
- 天线恢复：两个独立 Core 进程间审批续接、MCP 重启取回、补画、用户修改保护、部分导入补齐、图片 HTTP 预览和持久工具事件，不新增求解。
- 前端：Vitest 全量 + Chromium 真实渲染；lint、Prettier、vue-tsc 作为 CI 门禁。
- 评测：42 个个人任务与参考脚本（reference 模式，脚本模型）；评判器区分越权“尝试/执行”，支持审批复用、过期版本重放探针和 `--safety-layer off` 对照组。
- LIVE 基线（2026-11-27，本地网关 GLM-5.4，42 × 3）：严格通过 89/126，剔除字面回复后 122/126，注入尝试 0/24；4 个真实行为失败全在审批流程（1 次谎报写入、1 次以文字代替工具申请、2 次跳过申请步骤）。细节与 B 组见 [Agent 行为评测](../testing/AgentEvals.md#首次-live-基线2026-11-27glm-54)。

**性能基准**（2026-10-16，Linux，真实 Chromium，220 条历史滚动 180 帧采样）

| 场景 | P50 / P95 / P99 帧时间 | 长任务 | Paint / Raster 总计 |
| --- | --- | --- | --- |
| 无背景图 | 16.8 / 33.4 / 50.0 ms | 1 次 55 ms | 1222.3 / 744.1 ms |
| 有背景图 | 16.7 / 33.4 / 33.5 ms | 1 次 127 ms | 1274.9 / 634.9 ms |

案头背景 48 个截图状态、2,254 个可见文字矩形：正文最低对比度 8.620:1，其余最低 4.512:1，0 页面异常。长会话的 127 ms 长任务尚未关闭。

## 3. 当前已知限制

- 真实模型服务：评测已在本机网关的 GLM-5.4 上跑过 LIVE A/B；其他 Provider、思考/缓存效果、自然语言选模和额度查询仍未验证。模型会把“发起受限工具调用即进入审批”误解为“没有审批机制”，工具描述层面待改进。
- 平台：Windows 实机启动、PowerShell、SRT 沙箱、桌面安装包和 runtime bundling 未完成；macOS 未验证。
- 安全审查模型有已知缺陷：LAYA 日语漏拦、阿拉伯语误拦、印地语/XPU 崩溃、KEV 部分注入漏拦。
- 恢复语义：LangGraph 恢复是 at-least-once；浏览器页面不能跨 Core 重启保留；含 delegate 的中断任务暂不能从公共恢复接口重跑；审批/回答的跨进程恢复、快照并发/截断、投影异常注入尚未覆盖。
- 权限：窄授权撤销/过期、运行中模式变更、公共网页会话授权、子 Agent 取消/撤销/共享预算的全矩阵未覆盖；Provider 非唯一工具调用 ID 的命名空间转换未实现。
- MCP / Skill：密钥链凭证重启/轮换、EOF/并发恢复/断线应用、目录扫描超限/取消、扩展设置 GUI 全流程未覆盖。
- 浏览器：真实账号登录、超时/关闭失败、容量/空闲回收未覆盖；公共 HTTP 校验不是完整网络沙箱。
- 文档 / OCR：损坏/加密/超限文档、取消清理、OCR 语言准确率与 Windows 未验证；完整 Office 版式、live 引用、图生图及音视频不在当前能力内。
- 上下文：压缩/容量接线只做过本机协议验证，LM Studio 与 Anthropic 实时行为未验；缓存命中率没有实测数据。
- 天线扩展：自然语言自主编排、完整 GUI、Windows、运行中强杀恢复未验收；连续带宽、网格收敛和实物性能未验证，固定理想匹配在 21.3 MHz 的 SWR 约为 8.19。
- 未交付：手机远程访问、持久工作流、后台/可写子 Agent、自动记忆提取、语义/向量检索、自动路由/降级、手动压缩 API。

- 安全续跑、受控重试、并发预算和超时。

- 扩展健康管理和热重载。
- 记忆多目录、修改/续接、超预算；自动提取和语义检索。
- 模型自动路由/降级、向量嵌入/索引。
- 天线扩展：自然语言交互、模型预算、平台测试与工程验证。

暂不展开：团队管理、PostgreSQL 团队部署、分布式执行、自研工作流引擎、插件框架、事件溯源。
