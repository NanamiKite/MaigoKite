# 安装与首次使用

目前需要从源码运行，可以选择 Web 或 Electron 桌面入口。独立桌面安装包尚未完成验收，也不支持 Docker/服务器部署。构建与发布限制见 [构建与发布指南](../deployment/ReleaseGuide.md)。

## 1. 从源码启动

先按 [开发指南](../development/DevelopmentGuide.md) 安装指定版本的依赖，并运行 setup 脚本。Linux 使用 `bash scripts/start.sh web|desktop`，Windows 使用 `scripts/start.ps1 web|desktop`；其中 web 和 desktop 二选一。

两个入口都会启动整套本地服务，不要同时运行，也不需要 Make。

源码运行需要 Python 3.14.x、Node/npm 和 ripgrep（`rg`），具体版本见开发指南。未来的正式安装包应包含所需运行资源，不能要求普通用户自行安装开发环境。

## 2. 首次使用

1. 启动后会建立个人工作区。产品不提供团队邀请或团队管理。
2. 在模型设置中添加服务地址和实际模型 ID。验证连接后选择默认模型；也可以为会话单独选择模型。
3. 通过设置中的凭证入口或受支持的环境变量提供 API 密钥，不要写入普通 YAML。
4. 选择权限模式，确认工作区路径，查看应用服务的运行状态，再开始测试对话。

权限、模型、本地服务与工具设置见 [配置指南](Configuration.md)。显示“规划中”的页面，或仅有页面入口的功能，不表示已经可用。

## 3. 常见启动问题

- **设置保存 404**：确认连接的是当前 Python 后端，再检查前端代理、服务版本和启动状态。不必反复填写凭证。
- **Python 不可用**：检查实际使用的解释器和依赖。Python 后端在 Core 初始化完成后提供 HTTP `/health`，默认地址为 `http://127.0.0.1:8080/health`。
- **Electron 安装不完整**：更新仓库后运行 `bash scripts/setup.sh electron`（Windows：`.\scripts\setup.ps1 electron`），再用 `start desktop built` 启动。重复编译不能补齐 Electron。新机器应先按开发指南安装受支持的 Node/npm，再执行完整 setup。
- **端口冲突**：检查是否同时启动了开发脚本和 Electron 管理的服务，再检查配置中的端口。
- **模型连得上却不能回答/调用工具**：确认真实模型 ID、模型提供方协议和服务端能力。HTTP 200 不代表响应中有正确的 completion。
- **LM Studio/兼容服务端点错误**：填写服务的 OpenAI-compatible 基础地址，通常包含 `/v1`；已有 `/v1` 时不会重复追加。不要填写完整 `/chat/completions` 地址，应用不保证剥离这个后缀，具体规则见模型接入设计。模型 ID 也不能用显示名称代替。
- **文件搜索失败**：确认 `rg` / `rg.exe` 位于工作区和搜索目录之外的绝对 PATH 目录。普通 `glob/grep` 不依赖命令沙箱，不需要为此开启完全访问。搜索范围和截断限制见[工作区工具](Configuration.md#工作区工具)。
- **受限命令不可用**：Linux 启动日志会区分 bubblewrap 缺失、参数不兼容、系统拒绝等原因；按提示处理并重启后端。应用不会删除隔离参数重试。Windows 可选后端见[配置指南](Configuration.md#windows-原生命令沙箱)。
- **联网搜索失败**：检查搜索工具的配置、凭证和网络。模型凭证不能自动用于配置搜索服务。
- **MCP/技能不可用**：检查实际加载状态，配置存在不表示能力已加载。MCP 使用受信服务配置，Skill 使用本地声明文件，不提供远程安装。
- **数据异常**：不要手改或直接复制活动 SQLite 文件；先按 [备份与恢复](../ops-security/Backup.md) 建立一致性副本。

## 4. 断线、停止与重启

WebSocket 断开或关闭页面都不会取消主机上的任务。需要停止时，请使用停止操作；能否完成取消仍受运行时和第三方工具的限制。

重新连接聊天时会分页补拉事件并去重，每页最多 1000 条，并非总共只能恢复 1000 条。订阅窗口和客户端投影仍有限制，不能据此保证任意断线都无遗漏；协议见 [API 设计](../design/API.md)。

核心服务重启不同于断网：中断任务不会一律自动续跑，浏览器的临时 session 也不能据此恢复。文件任务和审批能否继续，取决于 LangGraph 检查点及恢复资格；缺少检查点的历史任务不能续跑，应先检查已有副作用，再发起新任务。具体边界见 [智能体运行时设计](../design/AgentRuntime.md#历史任务交接)。

数据主要保存在本地 SQLite 和工作区文件中，凭证存放在操作系统凭证存储中。手工管理记忆不等于自动知识检索。更多排查方法见 [日志与诊断](../ops-security/Observability.md)。

手机远程访问尚未交付，不应直接公开本地端口。
