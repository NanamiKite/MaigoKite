# MMANA 工程兼容性评估

当前窄 spike 已形成技术选型结论：**采用未修改的 pymininec，明确子集的[独立薄适配入口](../../extensions/antenna_design/README.md)已编码，不提取或重写内核。** 新入口本轮只做静态检查，尚未行为/数值验收。最近追加的五次材料计算与复电流分析见 `artifacts/closure-review-20261019/`；馈点身份、冻结接线下的幅相与五点材料趋势已有证据，方环缺行、通用模型和实物适用范围仍显式限制。技术选型完成不等于生产兼容验收通过。

六例工程主频参考和最新 **23/23 项多导线/扫频参考**已经通过 [Windows 自动采集](windows/README.md) 收齐并完成数值对照，详见[工程评估](ENGINEERING.md)。参考包含 GAL 1.2.0.20 的实际 EXE hash、另存模型、原始电流/远场和设置证据；GUI 脚本仅用于开发采集，不进入生产 MCP。五点扫频已对照，完整细频 `-Sweep` 未运行。

三个多导线模型（倒 V / 方环 / 三元 Yagi）在原 **9 次候选求解**后追加 **6 次有界网格诊断**，全部复用公共 solver API。Yagi 使用独立原生渐变分段后，固定轴 F/B 差异由约 2.54 dB 缩小为 0.23 dB；没有拟合尺寸或复制 GAL 分段。报告在 `artifacts/next-reviewed-20261019/` 与 `artifacts/geometry-refinement-20261019/`，详情见[后续批次](ENGINEERING.md#后续批次多导线与有界扫频)。**本批无需再次运行 Windows 采集**；新增复电流比较见文首，方向图深零陷、接线覆盖和材料表示仍有明确边界，不是普适兼容认证。

目标是在明确支持的模型范围内正确表达物理条件，输出能在 MMANA-GAL 中验证的工程结果。A01/A02 用简单导线诊断馈点、坐标和数值差异；后续检查材料、负载、地面、扫频及各自网格的收敛。不是复制 GAL 的 pulse 编排或求解器浮点结果，也不实现工作流、MCP、优化器、LangGraph、数据库或通用 MAA 转换器。

## 验收口径

- `.maa` 可读写，物理几何、连接、材料、地面、源/负载的位置和单位不能变。两端的离散网格可以不同，保存实际网格并分别检查加密后的稳定性。
- 核对会改变设计决定的结果：阻抗、谐振与 SWR 带宽、主后瓣/增益、电流分布和材料损耗。工程误差标准按用途、制造与测量条件预先确定，不以小数末位相同为标准。
- 原始方向图和电流仍是一等证据；同网格逐点差异是有效的诊断方法，不是唯一验收方式，更不代表要求每个点相等。不同网格的对照必须说明物理位置和必要的重采样。
- 现有约 0.003 dB 的 RMS 不再驱动常数补偿或网格逆向。自动分段算法未复刻不阻塞材料/地面验证；不能表达物理馈点、负载或模型不收敛，才构成需要处理的问题。

历史 JSON、脚本快照及数值差异保持原样；新的工程验收口径不把旧 `DIFFERENCES_RECORDED` 偷改为 PASS。当前是继续采用 pymininec 做工程评估，不是宣称任意 MMANA 模型“完全兼容”。

## A01 原始基线：在 MMANA-GAL 中手工输入

新建空模型，名称建议 `A01-uniform20`。坐标显示单位选米，频率填 **145 MHz**。

几何表只填一行：

| X1 (m) | Y1 (m) | Z1 (m) | X2 (m) | Y2 (m) | Z2 (m) | R (mm) | SEG |
| --- | --- | --- | --- | --- | --- | --- | --- |
| -0.5 | 0 | 0 | 0.5 | 0 | 0 | 1 | 20 |

`R` 是半径，**不是直径**；这里直径为 2 mm。整根导线长 1 m，不要拆成两根，不要添加馈电间隙。A01 的 SEG 填正数 20，不能填 0 或 -1；自动分段另用 A02 的独立采集文件，不修改这份基线。

保持顶部 DM1/DM2/SC/EC 的当前值并一并保存；不要把 DM2 改为 20 来代替导线行的 SEG。本次固定均匀分段只用于基线对照，不是日常设计的通用推荐。

源只填一行：

| Pulse / 位置 | Phase (deg) | Voltage (V) |
| --- | --- | --- |
| w1c | 0 | 1 |

`w1c` 中间是数字 `1`，不是小写字母 `l`。源位置拼写错误时即使显示了阻抗，也不能作为有效计算结果。

其他设置：

- 无集中负载，无匹配网络，无馈线变换。
- Ground 选 **Free space / 自由空间**，不是 Perfect ground / 理想地面。
- 导体损耗关闭或材料选 **No loss / 无损**，不是铜或铝。保留实际版本界面中的名称。
- 附加架设高度为 0；SWR 参考阻抗为 **50 Ω**。
- 不优化、不调谐、不改频率、不加密网格。
- 方向图使用绝对 **dBi**、**Total** 总场；保留 V/H 数据，不只导出 normalized 图。帮助中的界面 `V+H` 是分量叠加显示，不能直接当作 `Total` 的别名。

先保存 `A01-uniform20.maa`，再计算。菜单名称随语言/版本变化；如果某项找不到，请提供对应设置页截图，不要以另一个选项代替。

MMANA 帮助中的 R/SEG/源和 CSV 说明是设置依据；旧手册不能替代本次实际 GAL 版本及导出结果。[帮助文档](https://hamsoft.ca/pages/mmana-gal/mmana-gal_basic_help/MMANA-GAL%20basic%20help.htm)

## 候选侧

`probe.py` 只调用 pymininec 1.2.0 的现成计算和原始输出，不改求解算法。按 pulse 实际坐标寻找唯一中心源，不根据 GUI 中的编号猜 Python 索引。输出同时保存 solver 原生文本、复电流/网格和结构化远场。

```text
uv venv --python 3.14 <新的独立环境目录>
uv pip install --python <spike-python> pymininec==1.2.0 numpy==2.5.4 scipy==1.18.1 matplotlib==3.11.2
```

`<spike-python>` 是独立环境中的 Python 可执行文件，不是项目 `.venv`。这些是本次实际安装版本；matplotlib 是该 pymininec 发布版的依赖，本次未调用绘图。其余间接依赖和平台信息保存在 `environment.json`；若需完全重建同一环境，应同时使用其中记录的版本。不要根据主分支接口运行其他版本：1.2.0 的远场属性是 `gain`，与评估时主分支的 `gain_dbi` 不同。
